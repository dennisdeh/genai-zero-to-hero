## Sources
The material in this section is based on the following sources, which are provided for your reference and transparency. 
The sources have served as inspiration for the content in this section and modified for this project as needed. 
Please note that the content of these sources may be out of date.
The references listed below also serve as additional resources for to be explored if you want to go deeper into the topic.


### Books:
- D. Jurafsky, J. H. Martin, Speech and Language Processing, 3rd edition draft, chapter 2 "Regular Expressions,
  Tokenization, Edit Distance": https://web.stanford.edu/~jurafsky/slp3/
- J. Leskovec, A. Rajaraman, J. D. Ullman, Mining of Massive Datasets, chapter 3 "Finding Similar Items"
  (shingling, MinHash, LSH): http://www.mmds.org/

### Tutorials:
- Hugging Face LLM course - Byte-Pair Encoding tokenization: https://huggingface.co/learn/llm-course/chapter6/5
- Hugging Face `tokenizers` documentation: https://huggingface.co/docs/tokenizers/
- tiktoken README: https://github.com/openai/tiktoken
- Python documentation - `unicodedata`: https://docs.python.org/3/library/unicodedata.html
- Python documentation - Unicode HOWTO: https://docs.python.org/3/howto/unicode.html
- Unicode Standard Annex #15 - Unicode Normalization Forms: https://unicode.org/reports/tr15/

### Articles:
- P. Gage, A New Algorithm for Data Compression, C Users Journal 12(2) (1994)
- R. Sennrich, B. Haddow, A. Birch, Neural Machine Translation of Rare Words with Subword Units, ACL (2016):
  https://arxiv.org/abs/1508.07909
- A. Radford et al., Language Models are Unsupervised Multitask Learners (GPT-2, byte-level BPE), OpenAI (2019)
- T. Kudo, J. Richardson, SentencePiece: A simple and language independent subword tokenizer and detokenizer
  for Neural Text Processing, EMNLP (2018): https://arxiv.org/abs/1808.06226
- K. Lee et al., Deduplicating Training Data Makes Language Models Better, ACL (2022): https://arxiv.org/abs/2107.06499

### Videos lectures:

### Code Repositories:
