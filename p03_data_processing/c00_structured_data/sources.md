## Sources
The material in this section is based on the following sources, which are provided for your reference and transparency. 
The sources have served as inspiration for the content in this section and modified for this project as needed. 
Please note that the content of these sources may be out of date.
The references listed below also serve as additional resources for to be explored if you want to go deeper into the topic.


### Books:
- W. McKinney, Python for Data Analysis, 3rd edition, O'Reilly (2022), open access: https://wesmckinney.com/book/
- J. W. Tukey, Exploratory Data Analysis, Addison-Wesley (1977) - origin of the box plot and the IQR outlier rule
- T. Hastie, R. Tibshirani, J. Friedman, The Elements of Statistical Learning, 2nd edition, Springer (2009),
  section 7.10.2 "The Wrong and Right Way to Do Cross-validation": https://hastie.su.domains/ElemStatLearn/

- pandas user guide - time series / date functionality: https://pandas.pydata.org/docs/user_guide/timeseries.html
