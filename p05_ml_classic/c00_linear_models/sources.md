## Sources
The material in this section is based on the following sources, which are provided for your reference and transparency. 
The sources have served as inspiration for the content in this section and modified for this project as needed. 
Please note that the content of these sources may be out of date.
The references listed below also serve as additional resources for to be explored if you want to go deeper into the topic.


### Books:
- T. Hastie, R. Tibshirani, J. Friedman: The Elements of Statistical Learning, 2nd ed., Springer (2009), free PDF: https://hastie.su.domains/ElemStatLearn/
- G. James, D. Witten, T. Hastie, R. Tibshirani (and J. Taylor): An Introduction to Statistical Learning, with Applications in R / Python, Springer, free PDF: https://www.statlearning.com/
- C. M. Bishop: Pattern Recognition and Machine Learning, Springer (2006)
- A. Géron: Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow, O'Reilly

### Tutorials:
- scikit-learn user guide - linear models: https://scikit-learn.org/stable/modules/linear_model.html
- scikit-learn user guide - probability calibration: https://scikit-learn.org/stable/modules/calibration.html
- scikit-learn user guide - decision trees: https://scikit-learn.org/stable/modules/tree.html
- scikit-learn user guide - ensembles (random forests, gradient boosting): https://scikit-learn.org/stable/modules/ensemble.html
- scikit-learn user guide - support vector machines: https://scikit-learn.org/stable/modules/svm.html

### Articles:
- A. E. Hoerl, R. W. Kennard: Ridge Regression: Biased Estimation for Nonorthogonal Problems, Technometrics 12 (1970)
- R. Tibshirani: Regression Shrinkage and Selection via the Lasso, Journal of the Royal Statistical Society B 58 (1996)
- H. Zou, T. Hastie: Regularization and Variable Selection via the Elastic Net, Journal of the Royal Statistical Society B 67 (2005)
- L. Breiman: Random Forests, Machine Learning 45 (2001)
- C. Cortes, V. Vapnik: Support-Vector Networks, Machine Learning 20 (1995)
- A. Niculescu-Mizil, R. Caruana: Predicting Good Probabilities with Supervised Learning, ICML (2005)
