## Sources
The material in this section is based on the following sources, which are provided for your reference and transparency. 
The sources have served as inspiration for the content in this section and modified for this project as needed. 
Please note that the content of these sources may be out of date.
The references listed below also serve as additional resources for to be explored if you want to go deeper into the topic.


### Books:
- Martin Kleppmann: Designing Data-Intensive Applications, O'Reilly, 2017 (chapters on storage, encoding and batch processing)
- Joe Reis, Matt Housley: Fundamentals of Data Engineering, O'Reilly, 2022

- SQLAlchemy unified tutorial: https://docs.sqlalchemy.org/en/20/tutorial/
- SQLite documentation: https://www.sqlite.org/docs.html
