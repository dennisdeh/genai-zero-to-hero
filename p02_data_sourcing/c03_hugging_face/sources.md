## Sources
The material in this section is based on the following sources, which are provided for your reference and transparency. 
The sources have served as inspiration for the content in this section and modified for this project as needed. 
Please note that the content of these sources may be out of date.
The references listed below also serve as additional resources for to be explored if you want to go deeper into the topic.


### Books:
- Lewis Tunstall, Leandro von Werra, Thomas Wolf: Natural Language Processing with Transformers, O'Reilly, 2022 (chapters on datasets and dealing with few or large datasets)

### Tutorials:
- Hugging Face `datasets` documentation: https://huggingface.co/docs/datasets
- Streaming: https://huggingface.co/docs/datasets/stream
- Processing (map, filter, splits): https://huggingface.co/docs/datasets/process
- `huggingface_hub` documentation (downloading files, searching the Hub): https://huggingface.co/docs/huggingface_hub
- Dataset cards: https://huggingface.co/docs/hub/datasets-cards

### Articles:
- Q. Lhoest et al.: Datasets: A Community Library for Natural Language Processing, EMNLP 2021 (System Demonstrations), arXiv:2109.02846
- B. Pang, L. Lee: Seeing stars: Exploiting class relationships for sentiment categorization with respect to rating scales, ACL 2005 (rotten_tomatoes data)
- A. L. Maas et al.: Learning Word Vectors for Sentiment Analysis, ACL 2011 (IMDB data)
- T. Gebru et al.: Datasheets for Datasets, Communications of the ACM 64(12), 2021
